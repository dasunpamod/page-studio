# PageStudio 🎨

> **The modern, drag-and-drop visual GUI builder for Python Tkinter.**  
> Design desktop user interfaces visually and generate clean, human-readable Python code instantly.  
> **Zero external dependencies required** — works with 100% standard Python on Windows, macOS, and Linux.

---

## ⚡ How to Open (No Terminal Needed!)

### 🪟 Windows
* **Desktop**: Double-click the **PageStudio** shortcut on your Desktop.
* **Folder**: Double-click **`PageStudio.pyw`** or **`PageStudio.bat`** in this folder.
* *(To recreate your desktop shortcut at any time, double-click `Create_Desktop_Shortcut.bat`)*

### 🍎 macOS
* **Finder**: Double-click **`PageStudio.command`** directly in Finder.
* **Native Mac App**: Run `./create_mac_app.sh` once to create `PageStudio.app`. You can then drag it to your **Applications** folder or Dock!

### 💻 Any Platform (Terminal)
```bash
python main.py
```

## ✨ Key Features

* **Zero Dependencies (`0 pip install`)**: Built entirely on standard Python (`tkinter` + `ttk`). It works out of the box on any machine with Python 3.8+.
* **All 42 Tk & ttk Widgets**:
  * **Standard Tk**: Button, Entry, Label, Checkbutton, Radiobutton, Combobox, Listbox, Text, Progressbar, Scale, Separator, Frame, LabelFrame, Canvas, Spinbox, Message, Menubutton, Popupmenu, Toplevel.
  * **Themed ttk**: TButton, TEntry, TLabel, TCheckbutton, TRadiobutton, TCombobox, TFrame, TLabelframe, TNotebook, TPanedwindow, TProgressbar, TScale, TSeparator, TSizegrip, TSpinbox, TMenubutton.
  * **Scrolled & Compound**: ScrolledText, ScrolledListbox, ScrolledTreeview, ScrolledEntry, ScrolledWindow, Treeview, Custom.
* **True Container Nesting**: Put buttons and inputs inside Frames or Notebook tabs. When you move the container, all child widgets move with it automatically!
* **Dedicated Visual Editors**:
  * 📋 **Menu Editor**: Build application menubars, nested submenus, check/radio options, and accelerators.
  * 📑 **Notebook Tab Editor**: Add, rename, and manage multi-page tab containers (`ttk.Notebook`).
  * 📊 **Treeview Column Editor**: Design multi-column tables with custom widths, headings, and alignments.
  * 🔤 **Font Chooser**: Visual typography picker with real-time text preview.
* **PAGE-Compatible 2-File Architecture**:
  * Generates clean separation of concerns:
    * `app.py`: GUI presentation code (exact placements, containers, styling).
    * `app_support.py`: Application logic, Tk variables (`StringVar`, `IntVar`), and callback functions.
  * **Your custom code is 100% safe!** You can add your own functions and logic to `app_support.py`; PageStudio preserves your code when you re-save or re-export from the visual editor.
* **Undo / Redo & Clipboard**: Full multi-level history (`Ctrl+Z`, `Ctrl+Y`), copy (`Ctrl+C`), cut (`Ctrl+X`), paste (`Ctrl+V`), and duplicate (`Ctrl+D`).
* **Live Code Preview**: See the Python code generate dynamically line-by-line as you build.

## 📁 What Files Does PageStudio Generate?

When you export your design, PageStudio gives you two clean Python files:

1. **`app.py` (GUI Design)**
   ```python
   # Generated by PageStudio - Visual GUI Generator for Python
   import tkinter as tk
   from tkinter import ttk
   import app_support

   class App:
       def __init__(self, root):
           self.root = root
           self.root.title("My Application")
           self.root.geometry("600x400")

           self.btn_submit = ttk.Button(self.root, text="Submit", command=app_support.on_submit)
           self.btn_submit.place(x=240, y=180, width=120, height=36)

   if __name__ == "__main__":
       root = tk.Tk()
       app = App(root)
       root.mainloop()
   ```

2. **`app_support.py` (Your Code & Event Handlers)**
   ```python
   # Application logic for app.py
   import tkinter as tk

   # Put your custom functions and variables here!
   def on_submit(*args):
       print("Button clicked!")
   ```
